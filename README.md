
# Personal Profile Website

## Project Overview
A responsive single-page personal profile website
built using HTML5, CSS3 and Vanilla JavaScript.

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript
- Git and GitHub
- GitHub Actions

## Project Structure
- index.html - Main webpage
- css/theme.css - Theme variables
- css/style.css - Website styling
- js/main.js - Interactive functionality
- images/ - Website images

## Development Workflow
- main: Production branch
- develop: Integration branch
- feature branches: Individual website sections
- fix branches: Bug fixes and integration fixes
- theme branches: Theme implementations
